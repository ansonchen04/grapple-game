## Workflow: Plan before implementing

- Before writing code for a new feature or nontrivial change, check if a plan already exists in `plans/` (e.g. `plans/rope-physics.md`).
- If no plan exists, write one first as a new markdown file under `plans/[plan-name].md` before touching code.
- Skip planning and go straight to implementation only if:
  - a matching plan already exists in `plans/`, or
  - the user explicitly says to implement / skip planning.
